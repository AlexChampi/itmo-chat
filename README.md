# Chat (Android, ДЗ «Просмотр чатов»)

Клиент для просмотра каналов сервера [faerytea.name](https://faerytea.name/static/howto.md) на Kotlin и Jetpack Compose. Оформление в стиле One UI.

## Экраны

- **Чаты** (портрет): большой заголовок One UI, который при прокрутке сворачивается в шапку, и список каналов из `/channels` в карточке.
- **Сообщения** (портрет): `/channel/<имя>` порциями по 20 (`lastKnownId` + `reverse=true`), подгрузка старых при прокрутке вверх. Текст выводится как есть, картинки берутся из `/thumb/`. Стрелка в шапке возвращает к чатам.
- **Картинка**: `/img/` на весь экран. Закрывается крестиком, кнопкой или жестом «Назад». Тап по картинке прячет и показывает крестик.
- **Ландшафт**: слева список чатов, справа «Выберите чат» или сообщения. Открытый чат выделен в списке.

## Поведение

- Открытый чат и картинка хранятся в `SavedStateHandle`, поэтому переживают поворот и смерть процесса.
- Данные лежат во `ViewModel`, картинки в кэше Coil, так что поворот не ходит в сеть.
- «Назад»: закрывает картинку, если она открыта, иначе закрывает чат (на портрете это переход к списку), иначе выходит из приложения.
- Состояние неизменяемое: `data class` + `kotlinx.collections.immutable`.
- Ошибки сети показываются с кнопкой «Повторить».

## Библиотеки

Retrofit + OkHttp + kotlinx.serialization для сети, Coil 3 для картинок, Compose Material 3, Lifecycle ViewModel.

## Запуск в Android Studio

1. `File → Open` и выбрать папку **`chat`** (не корень репозитория).
2. Дождаться Gradle Sync (если попросит, установить Android SDK 37).
3. Запустить ▶ `app`.

Нужна Android Studio с поддержкой AGP 9.4 и JDK 17+ (подойдёт встроенный JBR).

## Сборка из командной строки

```
cd chat
./gradlew testDebugUnitTest lintDebug assembleDebug
```

## Структура

- `ChatApi.kt`: Retrofit-интерфейс, DTO и ссылки на `/thumb/` и `/img/`
- `Model.kt`: неизменяемые модели и состояние UI
- `ChatViewModel.kt`: загрузка каналов, пагинация, выбранный чат и картинка
- `ChatApp.kt`: раскладка портрет/ландшафт и обработка «Назад»
- `ChatsScreen.kt`, `MessagesScreen.kt`, `ImageScreen.kt`: экраны
- `Common.kt`, `Theme.kt`: аватары, кнопки и токены One UI
- `ChatApplication.kt`: общий OkHttp-клиент для Retrofit и Coil
